Review intent
This sheet does not block work. It helps the shift manager see missing operations, multiple cards, ordered-vs-produced differences, and totals before costing export.

The rows are generated from Database + hidden ActualsData when Refresh Review is clicked.

Hidden Storage Concept

Not shown to shift managers during normal use. Included here only to explain the structure.

Lightweight rule
ActualsData is a flat table with one row per operational card. Macros read and write rows on button clicks. The visible review sheet is refreshed on demand, avoiding complicated formulas and constant recalculation.
